# AURORA：七种心境

播放器提供七首完整轻音乐，分别对应开心、放松、专注、忧郁、充电、浪漫与助眠。选择心情后，对应曲目优先展示；播放由访客点击发起。原有本地 MP3 导入保留。

音乐根据作者提出的情绪与配器要求，由 Codex 编排旋律、和声与段落，使用 GeneralUser GS 2.0.3 采样乐器离线渲染，再进行响度与峰值处理，输出 44.1 kHz、192 kbps 的立体声 MP3。没有使用网易云音源，也没有在播放失败时切换成浏览器随机合成音。播放器未接入线上网易云后端。

GeneralUser GS 的许可证允许个人及商业音乐创作和录音使用；音色库不随网站分发。项目与许可证来源：https://github.com/mrbumpy409/GeneralUser-GS 。

曲目目录在 `assets/aurora/audio/`，情绪封面在 `assets/aurora/covers/`。构建源的曲库数据维护在 `src/data/tracks.ts`；更新曲目后，需要重新构建播放器并同步文章与公开全文。

页面展示统一使用“轻音乐”“完整聆听”或“播放”，不再使用“试听版”称呼这组曲目。TZBABY 已发布唱片仍在独立作品页，不与这七首播放器音乐混为同一专辑。
